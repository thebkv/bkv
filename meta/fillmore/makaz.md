# Makaz

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ma'-kaz

## Meanings

- end
- termination
- extremity
- objective
- aim
- ambition
- hope

## Biblical / Dictionary Context

A place in Israel. It is named in the portion of Israel from which Ben-deker gathered supplies for 
Solomon's household for one month in each year (I Kings 4:9).

## Metaphysical

The significance of Makaz is given under Ben-deker, since the two names are so 
closely related in the text. (See BEN— DEKER.)
