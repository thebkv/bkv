# Canneh

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** c an'-neh

## Meanings

- set up
- placed
- distinguished

## Biblical / Dictionary Context

It is thought to be the same city as Calneh (Ezek. 27:23).

## Metaphysical

Canneh was set up, or built up, in material thought. Its seeming eminence 
(distinguished) is short-lived because it is not established in Spirit, through trust in God. (See 
CALNEH.)
