# Zechariah

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** zech-a-ri'-ah

## Biblical / Dictionary Context

Name of twenty-eight Israelites (II Chron. 24:20; 26:5; Ezra 8:16; Zech. 1 :1, and so forth). 
Zachariah and Zacharias are forms of the same name.

See ZACHARIAH and ZACHARIAS.
