# Jerijah

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** je-ri-jah

## Biblical / Dictionary Context

A "chief" of the Hebronites, in David's reign (I Chron. 26:31). Jeriah is the same name.
