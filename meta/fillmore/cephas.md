# Cephas

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Gk
- **Pronunciation:** ce'-phas

## Meanings

- hard
- unyielding
- a stone
- rock
- cliff

## Biblical / Dictionary Context

A name that Jesus gave to Simon: "Thou shalt be called Cephas (which is by interpretation, 
Peter)." "That is, Rock or Stone, " (margin, John 1:42).

## Metaphysical

An unwavering faith in God. (See PETER.) When this faith is established firmly 
in individual consciousness, it becomes a rock, a sure foundation, unshakable, immovable, upon which 
one can build spiritually.
