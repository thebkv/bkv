# Johanan

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** jo-ha'-nan

## Biblical / Dictionary Context

There were several Israelites by this name, some of them men of note (I Chron. 3: 15, 24; 6: 10; 
12:4, 12; Ezra 8:12; Jer. 40:8, 13-16).

## Metaphysical

The love, mercy, largeness, broadness, and generosity of Spirit. (See JOHN, 
which is a contraction of this name.)
