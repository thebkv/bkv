# Ibhar

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ib-hSr

## Biblical / Dictionary Context

One of David's sons (II Sam. 5:15).

## Metaphysical

Desire and the thing desired. The root of this word refers to the object in which 
the will is centered and wherein it delights— the thing desired as well as the inner subjective force that 
sets the will in motion.
