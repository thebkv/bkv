# Hilkiah

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** hil-kiO-ah

## Biblical / Dictionary Context

a Father of Jeremiah (Jer. 1:1). b A high priest during Josiah's reign (II Kings 22:4-14). c There 
were several others by this name also (I Chron. 6:45; 26:11; Neh. 8:4; Isa. 22:20).

## Metaphysical

Consecration (my portion is Jehovah, especially set apart).

## Preserved OCR Source
