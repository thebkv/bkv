# Amramites

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** am'-ram-ltes

## Meanings

- belonging to Amram

## Biblical / Dictionary Context

Descendants of Amram, of the Kohathite Levites (Num. 3:27).

## Metaphysical

Thoughts springing from and of character like that in consciousness which 
Amram signifies. See AMRAM.
