# Geder

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ge'-der

## Biblical / Dictionary Context

A very old Canaanitish city that was captured by Joshua (Josh. 12:13).

## Metaphysical

The significance is the same as that of Beth-gader, which is believed to be the 
same city as Geder. (See BETH-GADER.)
