# Nineveh (in A.V., Luke 11:32, Nineve)

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** Luke 11:32, Nineve), nin-e-veh

## Biblical / Dictionary Context

A city of Assyria that was built by Asshur (Gen. 10:1 1, see margin). Jonah was sent to prophesy 
against this city (Jon. 1:2).
