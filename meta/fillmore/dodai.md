# Dodai

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** do'-dai

## Meanings

- loving
- amatory
- beloved ofJah
- his beloved

## Biblical / Dictionary Context

An Ahohite, captain of David's course of twenty-four thousand men for the second month of 
each year (I Chron. 7:4). Dodai is believed to be the same name as Dodo.
