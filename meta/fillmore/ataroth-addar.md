# Ataroth- addar

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** at'-a-roth-ad'-dar

## Meanings

- crowns ofaddar

## Biblical / Dictionary Context

A town on the eastern border of Ephraim (Josh. 16:5); some think that it is the same town as the 
Ataroth of Joshua 16:2, 7.
