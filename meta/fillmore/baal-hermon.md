# Baal-hermon

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ba'-al-her'-mon

## Biblical / Dictionary Context

A place near Mount Hermon (I Chron. 5 :23). It is supposed by some to be the same place as 
Baal-gad.

## Metaphysical

See BAAL-GAD. Mount Baal-hermon (Judg. 3 :3) seems to refer to a peak of this 
mountain itself— a peak of Hermon. As such it would symbolize the exalting of the formed and manifest 
world (the wonderful and sublime works of nature) above the unformed mind of Spirit.
