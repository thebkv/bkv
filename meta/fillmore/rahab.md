# Rahab

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ra'-hab

## Biblical / Dictionary Context

A symbolical name for Egypt (Psalms 89:10; Isa. 51:9).

## Metaphysical

The meanings of this name (outrageous, violent, tumult, fierce; courageous, 
proud, vain, insolent, a sea monster, crocodile ) all point to error ideas and activities that exist in the 
darkened, ignorant, sense consciousness in man. (Do not confuse this Rahab with the preceding one.)
