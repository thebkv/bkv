# Shuah

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** shu'-ah

## Biblical / Dictionary Context

Sixth son of Abraham by Keturah (Gen. 25:2).

## Metaphysical

An exceedingly depressed, downcast state of thought ( bowed down, despair, 
depression, pit).
