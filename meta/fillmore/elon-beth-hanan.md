# Elon-beth-hanan

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** e'-lon-beth-ha'-nan

## Biblical / Dictionary Context

A place in Palestine that constituted part of one of the commissary districts of Solomon (I Kings 
4:9). It is thought to be the same place as the Elon of Joshua 19:43.
