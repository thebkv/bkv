# Nehiloth

- **Corpus:** MBD
- **Type:** mbd_name

## Biblical / Dictionary Context

A name mentioned in the title of the 5th Psalm; in the margin, wind instruments is given.

## Metaphysical

(wind instruments, pipes, flutes).
