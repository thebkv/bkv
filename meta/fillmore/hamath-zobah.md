# Hamath-zobah

- **Corpus:** MBD
- **Type:** mbd_name
- **Language:** Heb
- **Pronunciation:** ha'-math-zo'-bah

## Biblical / Dictionary Context

A place in Syria that Solomon captured (II Chron. 8:3). It is thought to be the same place as 
Hamath.

## Metaphysical

A state of consciousness that is fortified in outer, material, intellectual reasonings 
and in that which Hamath signifies. (See HAMATH.) It has to give way, however, before true spiritual 
wisdom (represented here by Solomon, who captured Hamath-zobah).
